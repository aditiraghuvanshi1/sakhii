Sakhi is a privacy-first, single-file web application designed to support women across every stage of 
their health journey—ranging from menstrual wellness and reproductive years to pregnancy (Mother Watch) and
perimenopause/menopause (Change Companion).   The application is built entirely as a client-side static web app
with 100% on-device data privacy.  

🚀 Key Features🌸 
Cycle & Reproductive Health: Dynamic cycle phase calculator (Menstrual, Follicular, Ovulation, Luteal phases).
Interactive 90-day daily check-in tracker for mood, sleep, stress, energy, and cramps/pain.Visual interactive calendar
with cycle predictions and event logs.Quick-logging tools for period flow, symptoms, and intimacy.
Period reminders and .ics calendar export support.

🤰 Mother Watch (Pregnancy & Maternal Monitor): Trimester calculator and WHO-aligned antenatal care (ANC) appointment scheduler.
Tri-color maternal risk triage engine (Green/Amber/Red indicators for blood pressure and preeclampsia warning signs).
Built-in Edinburgh Postnatal Depression Scale (EPDS) postpartum mood screener.   
Multi-patient profile management for personal or community health worker use.  
Blood pressure and weight progression charts using Chart.js.  

🌿 Change Companion (Perimenopause & Menopause): Daily hot flash counter and symptom tracker 
(night sweats, brain fog, cycle irregularity).
Preventive health screenings tracker (Mammogram, Pap Smear, DEXA bone density scan).

💬 Ask Sakhi AI Health Assistant: Grounded Q&A assistant referencing official WHO and ICMR health guidelines.   
Multi-language support (English, Hindi, and Kannada) with real-time UI translation.   
Voice input support via Web Speech API.   
Myth-vs-fact interactive flip cards and verified clinic/telehealth directory (India focus).   

📄 Doctor Visit Summary Report: Generates a clean, 1-page medical summary of logged vitals, trends,
and risk triage statuses.   
Includes self-updatable patient notes and standard clinical discussion questions.   
Fully printable/exportable to PDF.   

🔒 Privacy & Data Storage100% On-Device: All personal check-ins, vitals, patient profiles, 
and logs are stored securely on your browser using localStorage.   
No data is sent to external cloud servers or databases.

🛠️ Tech Stack Frontend: HTML5, CSS3, Vanilla JavaScript (Single-File Architecture)   
Styling: Tailwind CSS (via CDN)   
Icons: Lucide Icons   
Charts: Chart.js   
Fonts: Hanken Grotesk, Newsreader, Plus Jakarta Sans, Noto Sans Devanagari, Noto Sans Kannada   

⚙️ Getting Started. Since Sakhi is packaged into a single standalone file (index.html),
running it locally requires no complex build tools or backend dependencies: Clone or download the repository 
containing index.html.Open the index.html file directly in any modern web browser (Chrome, Edge, Firefox, Safari).
Alternatively, you can host it statically on platforms like GitHub Pages, Vercel, or Netlify.

⚠️ Medical Disclaimer: Sakhi is designed as a personal wellness companion and health tracker. 
It provides WHO/ICMR-grounded health information but is NOT a substitute for professional medical diagnosis, advice, or 
treatment. Always consult a qualified healthcare provider for medical concerns.
